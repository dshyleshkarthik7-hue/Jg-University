#lJG University - Modern Landing Page

A modern and futuristic redesign of the JG University website for the CodingJr Internship Assignment.


**[View Live Website](https://jg-university.netlify.app/)**



This is a complete responsive landing page redesign inspired by [jguni.in](https://jguni.in/). The website features a sleek, futuristic "FutureVerse" theme with modern UI/UX.


- **Next.js 15** (App Router)
- **Tailwind CSS**
- **TypeScript**
- **Framer Motion** (for animations)



- Fully responsive design (Desktop + Mobile)
- Hero Section
- About Section
- Programs & Features
- Testimonials
- CTA Section
- Footer
- Smooth animations and interactions
